# 长剧情制作工作流程

这一版面向个人制作长篇 Ren'Py 剧情：按段落组织文本、批量录入、检查分支、安排演出，再交给 Ren'Py 检查与试玩。

## 第一次使用

1. 先保存旧窗口中的工程，再按 Ctrl+R 更新生成器。
2. 填写工程名称和主 label。主 label 是游戏通过 `call` 或 `jump` 进入故事的位置。
3. 保持「长篇模式」开启。每页最多 60 个步骤，只展开当前编辑的步骤；点击摘要就能编辑并查看舞台。
4. 在左侧「工程工具」中点击「读取游戏工程索引」，选择自己的游戏根目录或 game 目录。生成器只读取文件，收集 label、角色、图片和音频名称，用于填写建议与检查；动态定义不保证识别。

## 按章节与段落组织

用「剧情段落」建立 label，例如 `ch01_station`、`ch01_choice_a`、`ch02_home`。左侧目录可以搜索与切换段落。一个章节可由多个段落组成，目前使用命名约定组织章节，不提供独立的多级文件夹树。

新增步骤默认插在当前选中步骤之后，也可以改为追加到工程末尾。段落边界会补 return：想让剧情继续下一章，需要明确添加 jump 或 call。

「重命名当前段落」会同步更新选项、条件跳转、跳转和调用的目标。原始代码内的字符串引用不自动修改，需要自行检查。

## 快速录入与修改

- 「批量导入台词」每行一句，格式为 `e: 台词` 或 `旁白: 台词`；无角色前缀的行作为旁白。角色前缀使用游戏中的变量名，不是角色显示名称。
- 搜索支持台词、角色、图片名、备注；可叠加类型、制作状态、书签筛选。
- 制作状态为草稿、待处理、已校对；备注和书签不会写入游戏脚本。
- 勾选步骤左上角方框进行多选；可复制、删除、批量修改状态，或移动到指定段落末尾。多选可跨页保留；「取消多选」会清空。多选操作不包含 label，避免误拆段落。
- 「查找替换」只处理台词正文和制作备注，范围是当前段落或全部段落，不受关键词、类型等筛选影响；操作前显示匹配数量，并可撤销。

按段落批量写入对白，再逐段添加背景、立绘、声音和动画，通常比一开始逐句配置演出更容易维护。

## 检查分支

左侧「工程工具 → 检查剧情 / 分支」显示不存在的跳转目标、没有入口的段落、终止语句后通常无法执行的步骤，以及待处理项。点击提示可跳到步骤；下方段落关系表可跳转到分支目标。

未登记的缺失目标会阻止导出。目标若来自其他 .rpy 文件，请读取游戏索引，或在「外部 label」中登记。登记外部 label 表示由你负责保证它存在；静态索引也需要在游戏修改后重新读取。

检查不会执行 Python、推导全部条件路径或证明所有变量已初始化。自定义语句、动态跳转、原始代码和实际素材仍由 Ren'Py 检查。

## 保存、迁移与恢复

- 「保存工程」/ Ctrl+S：轻量 JSON，包含剧情、制作状态、画布设置和图片引用；不包含图片数据。
- 「打包工程与图片」：生成 `.rpe`，包含上述内容及素材库里导入的图片，可在另一台电脑通过「读取工程」恢复。图片总量上限 180 MB；缺失图片会阻止打包。**包内不含原游戏的外部音频、字体、脚本库及未导入的素材**，请另外备份整个游戏目录。
- 自动草稿使用 IndexedDB；约 400 毫秒后保存。顶部显示“已保存”才表示写入完成。关闭时如有未保存内容，浏览器会提醒。
- 大工程也可在重新打开后恢复，不依赖 localStorage 的小容量限制。每隔至少一分钟保存一次上一个版本作为备份，可用「恢复备份草稿」读取。
- 撤销历史最多 100 个状态，并以约 24 MB 为目标限制内存，至少保留 3 个状态。工程越大，可用撤销次数可能越少。浏览器关闭后不保留撤销历史。
- 同时只在一个窗口编辑同一份草稿，避免多个窗口互相覆盖。重要里程碑请另外保存 JSON 或 `.rpe` 文件。

## 导出与真实引擎验证

可继续使用「下载 .rpy」或「写入 Ren'Py 工程」输出单文件。也可在「工程工具」中选择「导出分段脚本包」，得到每个 label 一个 .rpy 的 ZIP。解压放入 game 即可；**同一内容不要同时保留整合脚本和分段脚本，否则 label 会重复**。更新分段包时，原来的旧文件不会由生成器自动删除，请先备份并自行整理。

双击项目根目录的 `打开工程检查工具.cmd`，会打开独立的「工程检查与试玩」窗口：

1. 选择包含 renpy.py 的 SDK 目录。
2. 选择包含 game 的游戏工程目录。
3. 点击「检查脚本」，阅读文件与行号提示；可保存报告。
4. 检查通过后点击「启动试玩」，逐条验证重要分支。

工具不绑定某台电脑的路径；请自行选择 SDK 与游戏目录，或通过 RENPY_SDK / RENPY_PROJECT 环境变量指定。它不会自动运行，也不会自动覆盖游戏脚本。检查和试玩由你点击启动，Ren'Py 会按正常方式生成缓存。

命令行检查示例：

```powershell
python tools/renpy_check.py --sdk 'D:\你的RenPySDK' --project 'D:\你的游戏工程' --lint --report './检查报告.txt'
```

可视化舞台仍是画面与单步动画预演，不等同于引擎：分支、Python 条件、声音、字体与最终显示行为以试玩为准。

## 本次验证与适用范围

已通过原功能、可视化与长篇三个浏览器回归套件，另验证分段 ZIP 的 CRC、解压内容及 Ren'Py lint。长篇测试包含 200 个命名段落、20,000 句对白，共 20,200 步；当前页最多渲染 60 张卡片。测试覆盖搜索末尾内容、编辑、数据库恢复、批量操作，以及在空浏览器资料中恢复带图片工程包。

本机无界面 Edge 的一次结果为首次更新约 72 毫秒、搜索约 22 毫秒（这是合成数据测试，并非所有设备或真实素材下的性能保证）。指标见 `tests/artifacts/performance-report.json`。

导入上限为 30,000 步；实际验证到 20,200 步。更大的项目可按章节拆成多个制作工程，使用外部 label 连接。舞台素材库仍最多 200 张图片，不适合一次载入全游戏的高分辨率素材；建议按制作工程拆分。
