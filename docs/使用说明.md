# Ren'Py 演出脚本生成器

长篇制作版的最新流程、工程打包、分支检查和引擎验证，请先阅读同目录的 [长剧情制作指南](长剧情制作指南.md)。下文保留演出与舞台操作细节。

继续使用桌面「Ren'Py演出脚本生成器」快捷方式。若窗口已打开，请先保存旧窗口中未导出的工程 JSON，再按 Ctrl+R 刷新。

## 功能整理（第三版）

| 分组 | 功能 |
| --- | --- |
| 画面与立绘 | 更换背景、清空画面、显示与隐藏自带淡入淡出、左中右站位、锚点、镜像、保留外观换表情 |
| 立绘动画 | 移动、缩放、旋转、透明度、跳动、左右抖动；可选匀速/缓入/缓出及等待完成 |
| 声音 | 音乐、音效统一支持播放、停止、排队、循环、播放音量和通道音量渐变；语音支持播放和停止 |
| 对白与节奏 | 台词、旁白、对话框显示/隐藏/自动、定时等待、等待点击、禁止点击提前结束 |
| 剧情流程 | 选项、命名段落、跳转、调用、条件跳转、变量赋值/增加/减少、返回 |

独立的「淡入淡出」「移动」「跳动」按钮已合并。旧工程自动迁移：旧淡入淡出转成透明度动画，旧移动/跳动转成立绘动画；旧声音步骤转成统一的声音控制。旧显示步骤保留原锚点和无转场行为。旧淡出仍保留透明立绘的旧行为，若希望彻底移除，请改用「隐藏立绘」。

此前的自动草稿、撤销重做、复制步骤、输入检查与写入备份仍保留。复制、下载和写入会阻止明显无效的输入；已有文件覆盖前确认并备份为 `.rpy.时间戳.bak`。

## 使用方法

### 可视化舞台

右侧新增可视化舞台。未导入素材时以带名称的占位图显示，也可以先排步骤、再绑定素材。

1. 展开「素材库」，导入图片或图片文件夹（PNG/JPEG/WebP/GIF；每张最多 30 MB，素材库最多 200 张）。
2. 点击一个场景或立绘步骤，点击素材的「用于当前步骤」。素材名必须与 Ren'Py 图片名一致，可在素材库中修改名称。重命名不会自动改写所有步骤，需重新绑定相关步骤。
3. 点击步骤卡片或编辑其中的参数，舞台显示执行到该步的画面；也可以用「上一步」「下一步」查看。
4. 选择「显示 / 更换立绘」的设置位置模式，或「立绘动画」的移动模式，在舞台内按住当前立绘拖动。松开后位置回写到 X/Y 参数及脚本，一次拖动可一次撤销；拖动时按 Esc 取消。
5. 「播放本步」预演当前步骤的移动、缩放、旋转、透明度、跳动、抖动及过渡；「停止」恢复本步结束画面。单次预演最多 60 秒。
6. 设置与游戏一致的画布宽高。画布尺寸仅用于编辑器预览，不会更改游戏的 `config.screen_width` / `config.screen_height`。图片按原始像素尺寸显示，不自动拉伸背景。

素材图片保存在当前浏览器的 IndexedDB；工程 JSON 和自动草稿只保存素材名称、图片引用与画布尺寸，不包含图片本体。换电脑或清理浏览器数据后，请移除失效引用并重新导入、绑定素材。原始图片不会自动复制到 Ren'Py 的 game 文件夹，游戏仍需自行具备图片定义和文件。移除素材引用可撤销；图片缓存会保留以支持恢复。

舞台是简化的分镜预览，不是 Ren'Py 引擎：不执行 Python、变量条件、跳转或声音；每个 label 从空白状态独立预览，不模拟调用前的画面。文本标签按原文显示，字体和对话框采用预览样式；擦除转场目前使用溶解近似，动画缓动与旋转边界也可能与引擎不同。最终效果请在 Ren'Py 试玩确认。

可视化回归测试为 `node tests/visual.cjs`，覆盖素材导入、绑定、拖动、撤销重做、动画与刷新恢复。历史版本备份不包含在发布包中。

### 脚本与工程

1. 从左侧添加步骤，填写参数；右侧脚本实时更新。
2. 图片名使用 Ren'Py 图片名，例如 `bg room`；音频路径相对于 `game` 文件夹，例如 `audio/theme.ogg`。
3. 菜单格式为 `选项文字 -> 目标label | 条件 | 效果`，条件和效果可省略。只填选项文字表示选择后继续执行后面的步骤。此简易格式不支持字段内包含分隔符 `|` 或 `->`。
4. 保存工程 JSON 用于以后继续编辑。下载 `.rpy` 或使用「写入 Ren'Py 工程」导出。
5. 在主脚本中使用 `call performance_1` 等语句调用生成的 label；图片定义、角色定义和跳转目标需要在游戏工程中存在。

`Ctrl+S` 保存工程；输入框外使用 `Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。在输入框内，撤销保留浏览器的文本编辑行为。也可点击顶部按钮撤销或重做整个步骤操作，最多保留 100 个历史状态。

草稿保存在当前浏览器的 IndexedDB，清理浏览器数据或换浏览器后可能无法恢复。请定期保存工程 JSON 或打包工程与图片。读取工程或清空后可通过撤销恢复本次窗口的旧内容。

新增动画默认开启「等待动画结束再继续」，关闭后可与台词同步。为兼容旧工程，旧动画默认不等待。普通定时等待可点击跳过，也可选择禁止点击提前结束；Ren’Py 的快进模式仍可能跳过等待。

显示立绘默认居中、底部对齐，预设可切换左中右；锚点表示立绘上的哪个位置与屏幕坐标对齐。换表情时选「保留现有位置与外观」。隐藏立绘可选择立即或淡出移除。

「切换场景」会清除当前主图层的立绘。声音控制中的通道音量会影响该通道后续播放；播放音量只影响当前文件。排队会等当前文件播放完成；循环音乐的队列行为由 Ren'Py 管理。语音应放在对应台词之前。

## 创建可用的剧情分支

1. 在主段落加入变量赋值，例如 `score = 0`，以及开场台词。
2. 加入选项：`进入 A -> branch_a` 和 `进入 B -> branch_b`。
3. 添加「剧情段落」，命名为 `branch_a`，在后面添加该分支的步骤。
4. 再添加段落 `branch_b`，填写另一个分支。段落边界自动补 return，避免从 A 意外执行到 B。最后一个段落也会补 return。
5. 「跳转 / 调用」的目标框会建议已定义的段落名。跳转不会返回；调用会在被调用段落 return 后回到下一步。
6. 条件跳转可填写满足和不满足时的目标；不满足目标留空就继续执行下一步。

同一工程内的段落名必须唯一；使用多个段落时必须勾选「包裹 label」。增加或减少变量前必须先赋值，或者在游戏脚本中用 default 初始化。条件和变量值使用 Ren’Py/Python 表达式，例如 `score >= 2`、`True`、`"名字"`。

可读取`examples/分支演出示例.json` 查看完整结构。示例引用 `e`、`bg room`、`eileen happy`，请按自己的游戏素材修改。

基础检查不执行原始代码与 Python 条件/效果，也不保证素材存在。长篇版另检查段落目标；跨文件目标需登记外部 label 或读取游戏索引。导出后仍应运行 Ren'Py 的「检查脚本」并试玩。

## 备份与验证

历史版本备份独立保留，不包含在正式发布包中。

生成器源码与 Ren'Py 游戏工程分开管理；整理程序目录不会修改游戏内容。

自动化浏览器测试：`node tests/regression.cjs`。该测试使用本机已安装的 Playwright Core 和独立的无界面 Edge，不使用日常浏览器资料。覆盖编辑、撤销重做、草稿恢复、边界数值、输入校验、JSON 导入导出、模拟目录写入/取消/备份及窄窗口布局。

开发阶段使用 Ren'Py 8.5.3.26051504 验证过代表性脚本；测试报告由测试生成至 `tests/artifacts/`，不随发布包分发。

语法参考：[Ren’Py 动画](https://www.renpy.org/doc/html/transforms.html)、[声音控制](https://www.renpy.org/doc/html/audio.html)。
